--- Sovereign Recon ---
A lightweight, native Go-based reconnaissance utility engineered for ethical security assessments and VAPT workflows. 

 Features
 ⚡ High-performance multi-threaded architecture.
 🛠️ Modular reconnaissance scanning modules.
 🔒 Integrated custom terminal banner and legal safety layouts.

 Installation & Usage on Kali Linux

Follow these steps to deploy and run **Sovereign Recon** natively inside your Kali Linux environment:
 Prerequisites
Ensure your system has the Go programming language installed. If you don't have it, install it using:
```bash
sudo apt update && sudo apt install golang -y
```
 Clone the repository
git clone [https://github.com/arjunraj-cyber/Sovereign-Recon.git](https://github.com/arjunraj-cyber/Sovereign-Recon.git)

cd Sovereign-Recon

go run main.go
